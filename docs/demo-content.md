## 演示脚本（对应课堂展示顺序）

1. 用**普通会员**登录，搜索含中文关键词（如"事件循环"）的文章并跳转。
2. 切**管理员**，发布一篇带"前端开发"标签的新文章，回前台验证。
3. 用**会员**在文章下发表评论，展示权限与错误状态。
4. 打开一篇"前端开发"文章，底部展示**相关推荐**面板（标签匹配 + 阅读时长）。
5. 展示 Git PR 与个人贡献，说明内容备份位置（`runtime/content/data` 的导出）。
